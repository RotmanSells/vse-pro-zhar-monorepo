## Out of Scope

- M14 Wheel + Quests implementation.
- Новые business features, rewards shop, redemption, campaigns, referrals.

## Architecture / Constraints

- Backend + PostgreSQL являются источником истины.
- Один modular monolith, один application process и одна canonical PostgreSQL database.
- Никаких Redis/Kafka/RabbitMQ/Kubernetes/microservices только ради closure.
- Все критические money/order/payment/refund/loyalty boundaries должны быть server-owned и idempotent.
- Prototype является visual source of truth; deviations require explicit owner decision.
- Existing functionality only; no fake UI claims for unavailable features.
