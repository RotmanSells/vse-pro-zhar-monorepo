Status: completed

## Purpose

Подготовить минимальный pnpm monorepo foundation для последующих приложений и общих пакетов.

## Current State

Исторический результат зафиксирован root commit `1954aeb` (`chore: initialize workspace foundation`). До последующего M0.2 в repository не было `apps/api` или `packages/contracts`.

## Scope

По фактам commit и текущих файлов были созданы:

- pnpm workspace и `pnpm-lock.yaml`;
- root `package.json` и root scripts `lint`, `typecheck`, `test`, `build`;
- общий строгий TypeScript foundation;
- flat ESLint foundation с запретами explicit `any` и `@ts-ignore`;
- `.gitignore` и `.env.example`;
- корневые `apps/` и `packages/` для будущих workspace packages;
- базовая README и проектная документация.

## Out of Scope

На этом этапе в commit отсутствуют Customer, Admin, API, Database и business functionality.

## Architecture / Constraints

Foundation использует обычный pnpm workspace и не добавляет отдельные task runners или инфраструктурные сервисы.

## Implementation Requirements

Root configuration должна оставаться пригодной для будущих Node/React packages, не создавая их заранее.

## Tests

В историческом commit нет application test suites. Root `test` и `build` предусмотрены как workspace orchestration с `--if-present`.
