# M0.2 — API + Shared Contracts Foundation

Status: completed
Milestone: M0
Depends on: M0.1 — Workspace Foundation (`1954aeb`)

## Purpose

Создать первую техническую вертикаль: shared runtime contract → Fastify API → validated HTTP response, без business functionality ресторана.

## Current State

Результат зафиксирован commit `9db311f` (`feat: add API and shared contracts foundation`) поверх M0.1. В repository присутствуют `packages/contracts` и `apps/api`.

## Scope

- `packages/contracts` с Zod `HealthResponseSchema`, `ApiErrorSchema` и выведенными TypeScript types;
- `apps/api` на Fastify;
- `GET /health` с `service`, `status`, `environment` и ISO `timestamp`;
- centralized runtime config через `APP_ENV`, `API_HOST`, `API_PORT`;
- safe API error envelope для unknown routes и unexpected errors;
- generated request IDs, независимые от произвольного внешнего `request-id`;
- Fastify/Pino structured request logging;
- graceful shutdown для `SIGINT` и `SIGTERM`;
- Fastify `inject` integration tests и config validation tests.

## Out of Scope

Customer, Admin, Database, PostgreSQL, Drizzle, authentication, catalog, orders, payments, iiko, loyalty и остальные business features.

## Architecture / Constraints

Backend остаётся простым будущим modular monolith. Application creation отделено от process listening: `buildApp()` можно проверять через Fastify `inject()`, а `server.ts` отвечает за запуск и shutdown.

## Implementation Requirements

API потребляет contracts как workspace dependency `@vse-pro-zhar/contracts`. Health response и error envelope проходят shared Zod runtime validation; internal error details не отправляются клиенту.

## Tests

В `apps/api/test` находятся:

- config tests для valid/default/invalid runtime config;
- HTTP tests для schema-valid `/health`, safe unknown-route error и unexpected error boundary.

Всего в этих файлах семь Vitest tests.
