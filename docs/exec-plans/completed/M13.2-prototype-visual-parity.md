## Architecture / Constraints

- Keep Expo/React Native native-target compatibility; web export is verification surface only.
- Keep Backend + PostgreSQL authoritative; UI renders confirmed state only.
- Reuse existing shared contracts, clients/controllers and screen boundaries.
- Keep lego boundaries: contracts → API client/controller → screen UI; no direct provider/database access from UI.
- No new infrastructure or dependency unless a measured visual requirement cannot be met with existing primitives.
- Prototype-only controls may remain visually unavailable/disabled, but must not pretend to work.
